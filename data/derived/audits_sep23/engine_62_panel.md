# Engine 6.2 review panel (Sep 23, night)

Five reviewers with distinct lenses (sender, nonces, no-shot path, scorer/runbook, feed counter) over the 6.1+6.2 change; every finding attacked by three independent refuters; confirmed = at most one refutation. 25 findings, 19 confirmed (duplicates across lenses counted separately). All confirmed defects were fixed in the commits that follow this file.

## Confirmed

  Fix: Use `state["shooter_nonce"].get(a, 0)` at line 1900 (the dry run never sends, the value only goes into the unsigned_tx log), or call refresh_shooters(gas=False) at start in dry run too (RPC is available there). The `+1`/restore paths are already guarded by `SEND is not None` / `if hh`, so nothing else touches the map in dry run.
